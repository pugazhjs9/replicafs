    Simulate a server crash

    docker compose stop node2
    docker compose start node2
    1. Upload a file and look at its chunk map: every row has 3 green boxes.
    2. Run the stop command in a terminal (inside ~/Projects/replicafs).
    3. node2's heartbeat timer fills up; after 10 s it turns DEAD.
    4. Watch new copies flash in on other nodes; every row returns to 3 live copies.
    5. Click Download: the SHA-256 still matches, with node2 down.
    6. Run the start command: node2 goes RECOVERING, then ALIVE.

    Simulate silent disk damage

    Click a green box in the chunk map to pick one stored copy.
    1. Copy the command and run it in the terminal. It changes a few bytes of that one copy directly on the node's disk, like a failing disk would. No error is raised.
    2. Click Check all copies now. The SHA-256 check finds the bad copy and stops trusting it. (Or just wait: the background scan re-checks every copy every 30 s, and what it finds also appears in Activity.)
    3. Within a few seconds, repair puts a good copy back from a healthy node. Download still matches ✓.
