# Learning ReplicaFS from zero

These docs assume you know Python and have built a REST API before, but know
**nothing** about distributed systems. Read them in order. Each one takes about
15 minutes.

| # | File | What you'll understand after reading it |
|---|---|---|
| 1 | [01-the-big-idea.md](01-the-big-idea.md) | What problem this solves and the 5 ideas the whole project is built on |
| 2 | [02-how-it-works.md](02-how-it-works.md) | What actually happens when you upload, download, or a node dies — step by step |
| 3 | [03-code-walkthrough.md](03-code-walkthrough.md) | Every file, every important function, and *why* it's written that way |
| 4 | [04-interview-questions.md](04-interview-questions.md) | The questions you will be asked about this project, with answers |
| 5 | [05-try-it-yourself.md](05-try-it-yourself.md) | Hands-on exercises: break things on purpose and watch the system react |

**Rule for reading:** whenever a doc mentions a file, open the real file next to it.
The code has comments that say *why* at every important line.
